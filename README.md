# Chá de panela  whallyson e Emylli

PROMPT — SITE PREMIUM E CINEMATOGRÁFICO | WHALLYSON & EMYLLI



Crie um site de convite digital premium para o Chá de Panela de Whallyson & Emylli, utilizando como principal referência visual a primeira imagem enviada nesta conversa.



A primeira imagem deve ser usada como referência de direção de arte, composição, tipografia, espaçamento, tratamento fotográfico, navegação e experiência visual.



A segunda imagem contém as informações oficiais do evento. Não altere, invente ou substitua essas informações.



Também vou enviar outras fotos posteriormente. Essas imagens deverão ser utilizadas no site para construir uma experiência visual semelhante a um editorial/campanha cinematográfica de casamento.



---



1. CONCEITO VISUAL



O site NÃO deve parecer um convite de casamento genérico, um template de Canva ou uma landing page criada automaticamente por IA.



Quero uma experiência:



- cinematográfica

- elegante

- sofisticada

- romântica

- minimalista

- misteriosa

- moderna

- editorial

- premium

- dark

- extremamente bem acabada



A inspiração deve combinar:



editorial de moda + fotografia cinematográfica + convite de casamento de luxo + design digital premium.



Use como base estética:



- preto

- azul-marinho extremamente escuro

- azul profundo

- branco/off-white

- pequenos detalhes em azul luminoso



Evite excesso de azul neon.



O azul deve aparecer como um acento sofisticado, não como uma interface gamer.

2. REFERÊNCIA PRINCIPAL



A primeira imagem enviada deve ser tratada como referência estrutural e estética.



Quero reproduzir principalmente:



- fundo escuro

- fotografia ocupando grandes áreas

- textos elegantes sobre as fotografias

- tipografia serifada sofisticada

- títulos em fonte script/calligraphy

- textos pequenos em caixa alta

- bastante espaço negativo

- composição assimétrica em algumas galerias

- seções separadas por grandes áreas de respiro

- sensação de revista/editorial

- navegação discreta

- transições suaves

- aparência premium



Não copie literalmente o conteúdo da referência.



Use a referência como inspiração de design e composição.
